# Estructura inicial del proyecto

Este documento registra la organización inicial del proyecto Innovatech Solutions.

## Carpetas principales

- `frontend/`: contendrá la aplicación web desarrollada en Next.js.
- `backend/`: contendrá la API desarrollada en NestJS.
- `docs/`: contendrá la documentación técnica y académica del proyecto.

## Ramas iniciales

- `main`: rama estable del proyecto.
- `develop`: rama principal de desarrollo.
- `docs/estructura-inicial`: rama usada para documentar la estructura base.
